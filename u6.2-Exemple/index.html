    Configuració de Xarxes amb Mikrotik

    Configuració 1

    Dins una xarxa amb acces a internet (10.0.0.0/16, gateway 10.0.0.1) hi volem afegir una altra gestionada pel router mikrotik (192.168.1.0/24). Amb les seguents condicions:

    1. La xarxa amb acces a internet és 10.0.0.0/16.
    2. El router tendrà una interfície dins la xarxa 10.0.0.0/16 i és la 10.0.150.4
    3. Cream una xarxa interna que serà la 192.168.1.0/24 i tendrà una interficie 192.168.1.1
    4. El computador desde on operam tendrà una ip 192.168.1.2 amb el gateway 192.168.1.1
    5. Volem configurar per que l'ordinador tengui acces a internet via 10.0.0.1

    1. Configurar la interfície per la xarxa amb accés a internet (10.0.0.0/16)

    Assignam la IP 10.0.150.4 a la interfície que connecta el router a la xarxa amb accés a Internet.

    Passos a Winbox:

    1. Obre Winbox i connecta't al router.
    2. Ves a IP → Addresses.
    3. Clica Add (+).
    4. A Address, escriu: 10.0.150.4/16.
    5. A Interface, selecciona: ether1 (o la interfície que connecta a Internet).
    6. Clica OK.

    2. Configurar la interfície per la xarxa interna (192.168.1.0/24)

    Assignam la IP 192.168.1.1 a la interfície que gestionarà la xarxa interna.

    Passos a Winbox:

    1. Ves a IP → Addresses.
    2. Clica Add (+).
    3. A Address, escriu: 192.168.1.1/24.
    4. A Interface, selecciona: ether2 (o la interfície assignada a la xarxa interna).
    5. Clica OK.

    3. Configurar el gateway per a la xarxa interna

    L'ordinador de la xarxa interna ha de tenir la següent configuració:

    • IP: 192.168.1.2
    • Gateway: 192.168.1.1

    Passos a Windows (Opcional, si configures manualment):

    1. Obre Panell de control → Xarxa i Internet → Centre de xarxes i recursos compartits.
    2. Clica Canvia la configuració de l'adaptador (al menú esquerre).
    3. Fes clic dret sobre la connexió i selecciona Propietats.
    4. Selecciona Protocol d’Internet versió 4 (TCP/IPv4) i clica Propietats.
    5. Marca Utilitza la següent adreça IP i introdueix:
      • IP: 192.168.1.2
      • Màscara de subxarxa: 255.255.255.0
      • Gateway predeterminat: 192.168.1.1
    6. Clica Acceptar i tanca totes les finestres.

    4. Configurar el NAT perquè la xarxa interna tingui accés a Internet

    Afegim una regla NAT perquè els dispositius de la xarxa interna (192.168.1.0/24) puguin sortir a Internet.

    Passos en Winbox:

    1. Ves a IP → Firewall.
    2. Aneu a la pestanya NAT i clica Add (+).
    3. A Chain, selecciona: srcnat.
    4. A Out Interface, selecciona: ether1 (o la interfície que connecta a Internet).
    5. Ves a la pestanya Action i selecciona: masquerade.
    6. Clica OK.

    5. Afegir la ruta per permetre l’accés a Internet

    Creem una ruta perquè el trànsit sortint es dirigeixi correctament cap al gateway de la xarxa amb Internet.

    Passos en Winbox:

    1. Ves a IP → Routes.
    2. Clica Add (+).
    3. A Dst. Address, escriu: 0.0.0.0/0.
    4. A Gateway, escriu: 10.0.0.1.
    5. Clica OK.

    6. Comprovació de la connexió

    Amb aquestes configuracions, l'ordinador 192.168.1.2 hauria de poder accedir a Internet passant pel router Mikrotik.

    Per verificar la connexió:

    1. Obre una consola de comandes a Windows (cmd).
    2. Executa: ping 8.8.8.8.
    3. Si reps resposta, la connexió funciona correctament.
    4. Si no funciona, revisa les configuracions de NAT i la ruta per Internet.

    Configuració 2

    Aplicam canvis a la configuració anterior on l'ordinador de control tengui el gateway a 10.0.150.4 i la ip 10.0.100.80. Configuram al mikrotik les regles per poder accedir a la direcció 192.168.1.5 el router li deixi accedir de forma rutes estàtiques.

    1. Configurar la interfície per la xarxa amb accés a internet (10.0.0.0/16)

    Assignam la IP 10.0.150.4 a la interfície que connecta el router a la xarxa amb accés a Internet.

    Passos en Winbox:

    1. Obre Winbox i connecta't al router.
    2. Ves a IP → Addresses.
    3. Clica Add (+).
    4. A Address, escriu: 10.0.150.4/16.

    6. Clica OK.

    2. Configurar la interfície per la xarxa interna (192.168.1.0/24)

    Assignam la IP 192.168.1.1 a la interfície que gestionarà la xarxa interna.

    Passos en Winbox:

    1. Ves a IP → Addresses.

    3. A Address, escriu: 192.168.1.1/24.

    3. Configurar el gateway per a l'ordinador de control

    L'ordinador de control ha de tenir la següent configuració:

    • IP: 10.0.100.80
    • Gateway: 10.0.150.4

    Passos a Windows (Opcional, si configures manualment):

    6. Clica Acceptar i tanca totes les finestres.

    4. Configurar el NAT perquè la xarxa interna tingui accés a Internet

    Afegim una regla NAT perquè els dispositius de la xarxa interna (192.168.1.0/24) puguin sortir a Internet.

    Passos en Winbox:

    1. Ves a IP → Firewall.
    2. Aneu a la pestanya NAT i clica Add (+).
    3. A Chain, selecciona: srcnat.
    4. A Out Interface, selecciona: ether1 (o la interfície que connecta a Internet).
    5. Ves a la pestanya Action i selecciona: masquerade.
    6. Clica OK.

    5. Afegir una ruta estàtica per accedir a 192.168.1.5 des de 10.0.100.80

    Perquè l'ordinador de control pugui accedir a la Raspberry Pi (192.168.1.5), hem d'afegir una ruta estàtica.

    Passos en Winbox:

    1. Ves a IP → Routes.
    2. Clica Add (+).
    3. A Dst. Address, escriu: 192.168.1.5/32.
    4. A Gateway, escriu: 192.168.1.1.
    5. Clica OK.

    6. Comprovació de la connexió a la Raspberry Pi

    Per verificar que l'ordinador de control pot accedir a la Raspberry Pi:

    Passos:

    1. Obre una consola de comandes a Windows (cmd).
    2. Executa: ping 192.168.1.5.
    3. Si reps resposta, la connexió funciona correctament.
    4. Per accedir a la càmera via Apache, obre un navegador i entra: http://192.168.1.5.

    Configuració 3

    En aquesta configuració tenim quatre routers Mikrotik connectats a la xarxa principal 10.0.0.0/16, cadascun amb la seva pròpia xarxa interna.

    Configuració 3

    Aquesta configuració permet que tots els dispositius de la xarxa 10.0.0.0/16 puguin accedir als dispositius interns de cada subxarxa connectada als quatre routers Mikrotik.

    5. Esquema de xarxa

                             ┌──────────────────────────┐
                         │ Xarxa Principal (LAN)   │
                         │       10.0.0.0/16       │
                         └──────────────────────────┘
                                     │
            ┌────────────────────────┴────────────────────────┐
       ┌────┴────┐       ┌────┴────┐       ┌────┴────┐       ┌────┴────┐
       │ Router1 │       │ Router2 │       │ Router3 │       │ Router4 │
       └────┬────┘       └────┬────┘       └────┬────┘       └────┬────┘
  ┌────────┴────────┐ ┌────────┴────────┐ ┌────────┴────────┐ ┌────────┴────────┐
  │ Xarxa interna 1 │ │ Xarxa interna 2 │ │ Xarxa interna 3 │ │ Xarxa interna 4 │
  └─────────────────┘ └─────────────────┘ └─────────────────┘ └─────────────────┘

    1. Taula de configuració per cada router Mikrotik

    Router Interfície a LAN (10.0.0.0/16) Interfície a xarxa interna Dispositiu intern accessible Ruta per accedir-hi
    Router 1 10.0.150.1 (ether1) 192.168.1.1 (ether2) 192.168.1.4 192.168.1.0/24 via 192.168.1.1
    Router 2 10.0.150.2 (ether1) 192.168.2.1 (ether2) 192.168.2.4 192.168.2.0/24 via 192.168.2.1
    Router 3 10.0.150.3 (ether1) 192.168.3.1 (ether2) 192.168.3.4 192.168.3.0/24 via 192.168.3.1
    Router 4 10.0.150.4 (ether1) 192.168.4.1 (ether2) 192.168.4.4 192.168.4.0/24 via 192.168.4.1

    2. Configuració de rutes estàtiques

    Router 1

    /ip route add dst-address=192.168.1.0/24 gateway=192.168.1.1
/ip route add dst-address=192.168.2.0/24 gateway=10.0.150.2
/ip route add dst-address=192.168.3.0/24 gateway=10.0.150.3
/ip route add dst-address=192.168.4.0/24 gateway=10.0.150.4

    Router 2

    /ip route add dst-address=192.168.2.0/24 gateway=192.168.2.1
/ip route add dst-address=192.168.1.0/24 gateway=10.0.150.1
/ip route add dst-address=192.168.3.0/24 gateway=10.0.150.3
/ip route add dst-address=192.168.4.0/24 gateway=10.0.150.4

    Router 3

    /ip route add dst-address=192.168.3.0/24 gateway=192.168.3.1
/ip route add dst-address=192.168.1.0/24 gateway=10.0.150.1
/ip route add dst-address=192.168.2.0/24 gateway=10.0.150.2
/ip route add dst-address=192.168.4.0/24 gateway=10.0.150.4

    Router 4

    /ip route add dst-address=192.168.4.0/24 gateway=192.168.4.1
/ip route add dst-address=192.168.1.0/24 gateway=10.0.150.1
/ip route add dst-address=192.168.2.0/24 gateway=10.0.150.2
/ip route add dst-address=192.168.3.0/24 gateway=10.0.150.3

    3. Configuració de NAT

    Si volem que els dispositius interns surtin a Internet, cal activar NAT a cada router:

    /ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

    4. Comprovació de la connexió

    Per verificar que qualsevol dispositiu de la xarxa 10.0.0.0/16 pot accedir als dispositius interns:

    ping 192.168.1.4
ping 192.168.2.4
ping 192.168.3.4
ping 192.168.4.4

    Accedir als dispositius via navegador (si tenen serveis web):

    • http://192.168.1.4
    • http://192.168.2.4
    • http://192.168.3.4
    • http://192.168.4.4
