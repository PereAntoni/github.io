Configuració de Xarxes amb Mikrotik

Configuració de Xarxes amb Mikrotik

1. Configurar la interfície per la xarxa amb accés a internet (10.0.0.0/16)

Assignam la IP 10.0.150.4 a la interfície que connecta el router a la xarxa amb accés a Internet.

Passos en Winbox:

  1. Obre Winbox i connecta't al router.
  2. Ves a IP → Addresses.
  3. Clica Add (+).
  4. A Address, escriu: 10.0.150.4/16.
  5. A Interface, selecciona: ether1 (o la interfície que connecta a Internet).
  6. Clica OK.

2. Configurar la interfície per la xarxa interna (192.168.1.0/24)

Assignam la IP 192.168.1.1 a la interfície que gestionarà la xarxa interna.

Passos en Winbox:

  1. Ves a IP → Addresses.
  2. Clica Add (+).
  3. A Address, escriu: 192.168.1.1/24.
  4. A Interface, selecciona: ether2 (o la interfície assignada a la xarxa interna).
  5. Clica OK.

3. Configurar el gateway per a la xarxa interna

L'ordinador de la xarxa interna ha de tenir la següent configuració:

  • IP: 192.168.1.2
  • Gateway: 192.168.1.1

Passos a Windows (Opcional, si configures manualment):

  1. Obre Panell de control → Xarxa i Internet → Centre de xarxes i recursos compartits.
  2. Clica Canvia la configuració de l'adaptador (al menú esquerre).
  3. Fes clic dret sobre la connexió i selecciona Propietats.
  4. Selecciona Protocol d’Internet versió 4 (TCP/IPv4) i clica Propietats.
  5. Marca Utilitza la següent adreça IP i introdueix:
    • IP: 192.168.1.2
    • Màscara de subxarxa: 255.255.255.0
    • Gateway predeterminat: 192.168.1.1
  6. Clica Acceptar i tanca totes les finestres.

4. Configurar el NAT perquè la xarxa interna tingui accés a Internet

Afegim una regla NAT perquè els dispositius de la xarxa interna (192.168.1.0/24) puguin sortir a Internet.

Passos en Winbox:

  1. Ves a IP → Firewall.
  2. Aneu a la pestanya NAT i clica Add (+).
  3. A Chain, selecciona: srcnat.
  4. A Out Interface, selecciona: ether1 (o la interfície que connecta a Internet).
  5. Ves a la pestanya Action i selecciona: masquerade.
  6. Clica OK.

5. Afegir la ruta per permetre l’accés a Internet

Creem una ruta perquè el trànsit sortint es dirigeixi correctament cap al gateway de la xarxa amb Internet.

Passos en Winbox:

  1. Ves a IP → Routes.
  2. Clica Add (+).
  3. A Dst. Address, escriu: 0.0.0.0/0.
  4. A Gateway, escriu: 10.0.0.1.
  5. Clica OK.

6. Comprovació de la connexió

Amb aquestes configuracions, l'ordinador 192.168.1.2 hauria de poder accedir a Internet passant pel router Mikrotik.

Per verificar la connexió:

  1. Obre una consola de comandes a Windows (cmd).
  2. Executa: ping 8.8.8.8.
  3. Si reps resposta, la connexió funciona correctament.
  4. Si no funciona, revisa les configuracions de NAT i la ruta per Internet.
