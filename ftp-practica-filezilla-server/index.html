    CREACIÓ GRUPS I USUARIS I PROVES

    Ha de tenir un grup administrador amb accces a totes les carpetes, una entrada anomim sense password que pot veure la carpeta public, un client que pot veure la carpeta public i la carpeta catàleg, treballador pot veure totes les carpetes i pot veure i editar la carpeta stock. Un grup departament de control pot veure i editar totes les carpetes. Es vol tenir també un detall de totes les entrades que s'han produit durant un temps. - Primer es creen les carpetes dins del servidor. - Seguidament s'han de crear els grups - Desprès a cada grup s'han de crear dos usuaris, el password de cada usuari i de cada grup és el mateix que el nom (pe: admin,admin). - Finalment s'han de fer les proves.

    3.1 Carpetes

    • /public: Carpeta accessible per a tots, inclòs accés anònim.
    • /cataleg: Carpeta amb informació sobre productes o serveis.
    • /stock: Carpeta amb informació de l'estoc de l'empresa.
    • /altres: Carpeta general per a documents interns.

    3.2 Grups i permisos

    Grup / Usuari Carpetes accessibles Permisos
    Administradors Totes les carpetes Veure i editar tot
    Accés anònim /public Veure només
    Clients /public, /cataleg Veure només
    Treballadors Totes les carpetes Veure tot, editar /stock
    Departament de control Totes les carpetes Veure i editar tot

    Notes: - L'accés anònim no requereix contrasenya. - Els clients només poden llegir informació, sense possibilitat de modificar. - Els treballadors poden modificar només la carpeta stock. - El departament de control té permisos complets per supervisar i modificar contingut.

    4. Registre d'entrades (logs)

    Per tal de fer un seguiment de totes les accions realitzades al servidor FTP, es configurarà un registre que inclogui:

    • Usuari que ha accedit
    • Carpeta accedida
    • Data i hora de l'accés
    • Tipus d'acció: lectura, escriptura, eliminació
    • IP d'origen
