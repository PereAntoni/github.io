    PRÀCTICA SCRIPT

    La pràctica consisteix en el joc endevina nombre. La màquina "pensa" un nombre i l'usuari l'ha d'endevinar.

    Descripció

    1. Pantalla on es pot iniciar/sortir del joc.
    2. Pantalla on es demana el nom del jugador.
    3. Comença partida
      1. El programa genera un nombre 'pensat' entre 0 i 100.
      2. L'usuari escriu un nombre 'x' entre 1 i 99.
      3. El programa contesta si és més alt o més baix del nombre 'pensat'.
      4. El programa compara si 'x' és igual a 'pensat'.
        1. Si x=pensat segueix al següent punt
        2. Sino: pasa al punt 2
    4. Pantalla Continuar o acabar.

    Valoracions

    1. Ús correcte i sòlid de funcions i programa main
    2. Comentaris de cada una de les funcions, variables i main
    3. Identació del codi
    4. Disseny d'interfície.
    5. Ampliacions

    Ampliacions

    Feim les ampliacions per ordre per tal de tenir les puntutacions adequades al nostre score d'assignatura ;)

    1. Al final mostrar el rànquing. Usar la instrucció echo que ens guardi dins un arxiu ranquing.txt.
    2. Mostra IP del servidor.
    3. Fes còpia de seguretat, afegir una opció al menú principal que sigui crear còpia de seguretat.
      • Crear carpeta copia-ranquings.
      • Dins "copia-ranquings" fer còpia del ranquing amb el nom la data i hora actual.
      • Copiar ranquing a FTP gimnèsia.
    4. Demanar el rang de nombres que pensa la màquina la màquina.
    5. A cada torn Mostrar per pantalla tots els nombres que ha provat l'usuari.

    6. Menú de control de partides (vols jugar, vols sortir, veure ranquing).

    7. Crear interfície estàtica usant ús de 'clear'. Per crear l'interfície pots usar la pàgina link.

    Entrega

    S'han d'entregar tres documents, el codi, document de proves i presentació on es mostra l'arquitectura del programa.

    1. Document:
      • Introducció a les Explicació del programa.
      • Fases de programa. Cada una amb una breu explicació dels objectius aconseguits, mostres del codi.
      • Proves de cada fase.
      • Adjuntam enllaços al codi.
    2. Codi:
      • Es presenten totes les fases del programa.
      • S'han d'ajuntar les versions del programa dins d'un arxiu comprimit.
      • En cas d'emprar git es pot usar el repositori com enllaç.
    3. Presentació:
      • Introducció breu
      • Aquitectura del programa en forma d'esquema. (variables, instruccions, condicions, ...)
      • Mostres del programa
      • Proves principals.
