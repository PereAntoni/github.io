Preguntes sobre MikroTik

Configuració router MikroTik

manual de referència
1. Connexió desde un ordinador.
Per connectar-te al router, pots utilitzar un **cable Ethernet RJ45** (Cat5e, Cat6 o superior). Si el teu ordinador no té port Ethernet, necessites un **adaptador USB a Ethernet**.
2. Detectar el router des del programa Winbox?
Obre Winbox i ves a la pestanya **"Neighbors"**. Fes clic a **"Refresh"** per veure els dispositius disponibles. Pots connectar-te mitjançant **MAC address** o IP. Si el router no apareix, assegura't que el Wi-Fi estigui desactivat i que la IP del teu PC estigui configurada manualment dins del mateix rang.
3. Al router, com es pot posar la IP per defecte a 10.0.210.1/16?
A Winbox, ves a **IP → Addresses**, esborra la IP existent i afegeix **10.0.210.1/16** a la interfície **bridge**. També pots fer-ho per terminal amb el següent comandament: 
/ip address add address=10.0.210.1/16 interface=bridge
4. Com puc canviar la contrasenya de l'usuari admin a "iesSineuRouter"?
A Winbox, ves a **System → Users**, selecciona l’usuari **admin** i canvia la contrasenya. Alternativament, pots utilitzar aquest comandament en terminal: 
/user set admin password=iesSineuRouter

CONNEXIÓ AL ROUTER MIKROTIK

Per connectar el teu ordinador portàtil al router MikroTik hEX S RB760iGS, depenent del tipus de connexió que necessitis, pots utilitzar els següents cables:

Connexió Ethernet (cable recomanat per a configuració i ús general)

Necessites un cable Ethernet RJ45 (Cat5e, Cat6 o superior) per connectar el port LAN del teu ordinador portàtil a un dels ports Ethernet del router (de l’1 al 5). Si el teu portàtil no té port Ethernet, pots fer servir un adaptador USB a Ethernet. Connexió a través de la consola (si necessites configuració avançada en CLI)

El MikroTik hEX S té un port sèrie (RJ45) per a connexió de consola. Per connectar-te des d’un portàtil necessites: Un cable RJ45 a DB9 (RS232). Un adaptador USB a RS232 (DB9), si el teu portàtil no té port sèrie. Un programa com PuTTY o Winbox per gestionar la configuració. Si només vols configurar el router de manera bàsica, el mètode més fàcil és connectar-te per Ethernet i accedir a la interfície web o a Winbox.

WINBOX

Si ja has connectat el teu portàtil al MikroTik hEX S RB760iGS mitjançant un cable Ethernet, segueix aquests passos per detectar-lo des de Winbox:

🔹 1. Obre Winbox Descarrega Winbox des del web oficial de MikroTik si encara no el tens. Executa'l al teu ordinador (no cal instal·lació). 🔹 2. Busca el router a la pestanya "Neighbors" A Winbox, ves a la pestanya "Neighbors". Fes clic a "Refresh" per actualitzar la llista. Ha d’aparèixer el teu router a la llista amb la seva MAC address i, si ja té una IP assignada, també es mostrarà. 🔹 3. Connexió per MAC o IP Si el router no té IP configurada o no la saps, fes clic a la MAC address del dispositiu i prem "Connect". Si el router té una IP per defecte (normalment 192.168.88.1), pots introduir aquesta IP a la casella "Connect To" i prémer "Connect". 🔹 4. Inici de sessió Usuari per defecte: admin Contrasenya per defecte: (deixa-la en blanc si és la primera connexió) Si no detecta el router, prova aquests passos: ✔️ Desactiva el Wi-Fi del portàtil (per evitar conflictes de xarxa). ✔️ Configura manualment la IP del teu PC a 192.168.88.2 amb màscara 255.255.255.0 i prova de connectar a 192.168.88.1. ✔️ Canvia de port Ethernet al router i reinicia’l. ✔️ Comprova el cable Ethernet o prova un altre.

Un cop connectat, podràs configurar-lo segons les teves necessitats. 🚀

INTEGRAR A LA XARXA D'AULA.

Pots configurar la IP per defecte del router MikroTik a 10.0.210.1/16 i canviar la contrasenya de l'usuari admin a "iesSineuRouter" seguint aquests passos a Winbox o per terminal (CLI).

🔹 Mètode 1: A través de Winbox Accedeix al router via Winbox (per MAC o IP).

Canvia la IP del router:

Ves a IP → Addresses. Esborra l’adreça existent 192.168.88.1/24 (si n'hi ha una). Prem "+" (Add) i afegeix: Address: 10.0.210.1/16 Interface: bridge (o ether1 si no tens bridge). Guarda-ho amb OK. Configura el DHCP Server (Opcional, si vols donar IPs automàtiques als clients):

Ves a IP → DHCP Server. Assegura't que la xarxa 10.0.210.0/16 està configurada correctament. Canvia la contrasenya de l’usuari admin:

Ves a System → Users. Selecciona l’usuari admin i fes clic a Set Password. Escriu iesSineuRouter i confirma-ho. Aplica i guarda la configuració:

Ves a System → Reboot per reiniciar el router amb els canvis aplicats. 🔹 Mètode 2: Via Terminal (CLI) Si prefereixes fer-ho per línia de comandes, obre New Terminal a Winbox o connecta’t per SSH i executa:

sh Copiar Editar /ip address add address=10.0.210.1/16 interface=bridge /user set admin password=iesSineuRouter

Després d’això, desconnecta i torna a connectar amb la nova IP: 10.0.210.1. 🚀
