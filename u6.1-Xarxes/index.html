CONNEXIÓ AL ROUTER MIKROTIK

Per connectar el teu ordinador portàtil al router MikroTik hEX S RB760iGS, depenent del tipus de connexió que necessitis, pots utilitzar els següents cables:

Connexió Ethernet (cable recomanat per a configuració i ús general)

Necessites un cable Ethernet RJ45 (Cat5e, Cat6 o superior) per connectar el port LAN del teu ordinador portàtil a un dels ports Ethernet del router (de l’1 al 5). Si el teu portàtil no té port Ethernet, pots fer servir un adaptador USB a Ethernet. Connexió a través de la consola (si necessites configuració avançada en CLI)

El MikroTik hEX S té un port sèrie (RJ45) per a connexió de consola. Per connectar-te des d’un portàtil necessites: Un cable RJ45 a DB9 (RS232). Un adaptador USB a RS232 (DB9), si el teu portàtil no té port sèrie. Un programa com PuTTY o Winbox per gestionar la configuració. Si només vols configurar el router de manera bàsica, el mètode més fàcil és connectar-te per Ethernet i accedir a la interfície web o a Winbox.

WINBOX

Si ja has connectat el teu portàtil al MikroTik hEX S RB760iGS mitjançant un cable Ethernet, segueix aquests passos per detectar-lo des de Winbox:

🔹 1. Obre Winbox Descarrega Winbox des del web oficial de MikroTik si encara no el tens. Executa'l al teu ordinador (no cal instal·lació). 🔹 2. Busca el router a la pestanya "Neighbors" A Winbox, ves a la pestanya "Neighbors". Fes clic a "Refresh" per actualitzar la llista. Ha d’aparèixer el teu router a la llista amb la seva MAC address i, si ja té una IP assignada, també es mostrarà. 🔹 3. Connexió per MAC o IP Si el router no té IP configurada o no la saps, fes clic a la MAC address del dispositiu i prem "Connect". Si el router té una IP per defecte (normalment 192.168.88.1), pots introduir aquesta IP a la casella "Connect To" i prémer "Connect". 🔹 4. Inici de sessió Usuari per defecte: admin Contrasenya per defecte: (deixa-la en blanc si és la primera connexió) Si no detecta el router, prova aquests passos: ✔️ Desactiva el Wi-Fi del portàtil (per evitar conflictes de xarxa). ✔️ Configura manualment la IP del teu PC a 192.168.88.2 amb màscara 255.255.255.0 i prova de connectar a 192.168.88.1. ✔️ Canvia de port Ethernet al router i reinicia’l. ✔️ Comprova el cable Ethernet o prova un altre.

Un cop connectat, podràs configurar-lo segons les teves necessitats. 🚀 Necessites ajuda amb algun pas?
