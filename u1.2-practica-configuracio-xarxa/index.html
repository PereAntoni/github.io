Guia: 5 Sessions — Sense DHCP i amb DNS intern

Guia docent — 5 sessions sense DHCP i amb DNS intern

Pla de 5 sessions adaptat per a un laboratori amb 6 Mikrotiks, 14 alumnes i xarxa comuna 10.0.0.0/16. Les IPs als clients seran manuals i cada Mikrotik oferirà un DNS intern per a la seva LAN.

Objectiu general

Els alumnes aprendran a configurar una xarxa amb Mikrotik que:

  • Gestiona IPs manuals en una LAN pròpia.
  • Proporciona accés a Internet mitjançant NAT.
  • Proporciona un DNS intern per resolució de noms locals i forwarding extern.
  • Permet rutes i proves entre diferents segments de xarxa.

Organització i adreçament

6 Mikrotiks físics — 14 alumnes. Grups de 2–3. Cada grup té 1 Mikrotik i 2 PCs/VMs. Xarxa comuna: 10.0.0.0/16. LANs de grup: 192.168.X.0/24.

Guia pas a pas per cada sessió

Sessió 1 — Configuració bàsica i IPs manuals

  1. Connectar-se al Mikrotik amb Winbox o WebFig.
  2. Assignar IPs al Mikrotik:
/ip address add address=10.0.0.10X/16 interface=ether1 comment="WAN"
/ip address add address=192.168.X.1/24 interface=ether2 comment="LAN"
  1. Configurar clients amb IP manual (ex: 192.168.X.10), gateway 192.168.X.1, DNS 192.168.X.1.
  2. Provar connectivitat local: /ping 192.168.X.1.

Sessió 2 — Ruta i NAT

/ip route add dst-address=0.0.0.0/0 gateway=10.0.0.1
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

Provar des d'un client: ping 8.8.8.8. Si respon, Internet OK.

Sessió 3 — Configurar DNS intern

Objectiu: el Mikrotik actua com a DNS forwarder i com a servidor de noms local.

/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes
/ip dns static add name=serverX.lab address=192.168.X.10
/ip dns static add name=routerX.lab address=192.168.X.1

Provar: ping routerX.lab i ping google.com.

Sessió 4 — Rutes entre LANs i seguretat

  1. Al router central, afegir rutes de tornada:
(router central)  
/ip route add dst-address=192.168.X.0/24 gateway=10.0.0.10X

Al Mikrotik, afegir regles de firewall per permetre trànsit desitjat:

/ip firewall filter add chain=forward src-address=10.0.0.0/16 dst-address=192.168.X.0/24 action=accept
/ip firewall filter add chain=forward src-address=192.168.X.0/24 dst-address=10.0.0.0/16 action=accept

Sessió 5 — Proves finals i documentació

Cada alumne ha de fer i anotar una bateria de proves (ping, DNS, rutes) i exportar la configuració:

/export file=config-grupX

Entregar: export + manual de proves completat + captures.

Comandes útils de diagnòstic: /ip route print, /ip firewall nat print, /ip dns cache print.

Guia per al professor

  • Verificar que cap grup té DHCP actiu a l'interfície WAN (10.0.0.0/16).
  • Comprovar la coherència del pla d'adreçament abans de començar.
  • Comprovar rutes de tornada al router central un cop s'introdueixen LANs privades.
  • Recol·lectar exports de configuració i revisar logs per incidències.

Notes de seguretat i bones pràctiques

  • No activar DHCP en la xarxa comuna per evitar conflictes.
  • Usar DNS intern per a noms locals i forwarding per a ressolució externa.
  • Desactivar serveis d'administració no necessaris i fer backups abans de canvis grans.
