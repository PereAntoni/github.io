    Servei DNS.

    Què és el servei DNS?

    El servei DNS (Domain Name System) és un sistema que tradueix els noms de domini (com ara www.gimnesia.net) en adreces IP comprensibles per als ordinadors (per exemple, 192.168.1.1). Això permet als usuaris accedir a llocs web utilitzant noms fàcils de recordar, en lloc d'adreces IP numèriques.

    Quan escrius una URL al navegador, el procés segueix els passos següents:

    1. El navegador envia una consulta DNS per obtenir l'adreça IP associada al nom de domini.
    2. El servidor DNS respon amb l'adreça IP corresponent.
    3. El navegador utilitza aquesta adreça IP per connectar-se al servidor web i mostrar el contingut.

    Exemples de connexió

    Exemple 1: Resolució del domini

        1. L'usuari escriu "www.gimnesia.net" al navegador.
    2. El sistema operatiu consulta el servidor DNS configurat.
    3. El servidor DNS respon amb l'adreça IP: 203.0.113.15.
    4. El navegador estableix una connexió amb el servidor web mitjançant aquesta adreça IP.

    Exemple 2: Traça de la connexió

        1. Ordre des del terminal: 
       tracert www.gimnesia.net (Windows)
       o 
       traceroute www.gimnesia.net (Linux/Mac).
    2. Resultat:
       salt 1: 192.168.1.1 -> Router local.
       salt 2: 10.0.0.1 -> Proveïdor d'Internet.
       salt 3: 203.0.113.15 -> Servidor final de www.gimnesia.net.

    Desenvolupaments

    Per implementar un sistema DNS, és fonamental entendre la seva estructura, funció i les tasques necessàries per gestionar-lo i implementar-lo. Els passos principals són els següents:

    Jerarquia de DNS

    El sistema DNS funciona com una jerarquia distribuïda que inclou els següents nivells:

    • Arrel: Representada per un punt (.), és el nivell superior de la jerarquia DNS.
    • Dominis de nivell superior (TLD): Com ara .com, .org, .edu, o .cat.
    • Dominis de segon nivell: Noms registrats dins d'un TLD, com projecte1.cat.
    • Subdominis: Particions d'un domini de segon nivell, com aula.projecte1.cat.

    Exemple: Quan un usuari escriu www.exemple.com, el DNS tradueix aquest nom a una adreça IP mitjançant la jerarquia.

    Tasques de gestió d'un administrador de DNS

    Un administrador de DNS és responsable de:

    • Configurar zones DNS i fitxers de zones per associar dominis a adreces IP.
    • Mantenir les dades DNS actualitzades i segures.
    • Fer còpies de seguretat i restauracions de configuracions.
    • Diagnosticar i solucionar problemes relacionats amb la resolució de noms.

    Aprendre a implementar un DNS

    A l'aula, es pot aprendre a implementar un servidor DNS usant eines com BIND i Webmin:

    • BIND: Un dels servidors DNS més populars i flexibles, configurat manualment mitjançant fitxers de configuració.
    • Webmin: Una interfície web per gestionar configuracions de BIND de manera visual i simplificada.

    Implementació

    Instal·lació de BIND9 i Webmin

    Per començar, cal instal·lar els paquets necessaris per al servidor DNS:

    • Instal·lar BIND9: sudo apt-get install bind9
    • Instal·lar Webmin: Seguir les instruccions de la pàgina oficial de Webmin.

    Agregar dominis amb Webmin

    Webmin proporciona una interfície gràfica per gestionar zones DNS de manera visual i simplificada. A continuació es detallen els passos per agregar un domini:

    1. Accedir al servidor Webmin:

      2. Obre un navegador i escriu l'adreça URL del servidor Webmin (normalment https://:10000).

    2. Iniciar sessió:

      3. Escriu les teves credencials d'administrador per iniciar sessió.

    3. Anar al mòdul BIND DNS Server:

      4. Un cop dins de Webmin, segueix aquesta ruta des del menú principal:

      • Servers (al menú lateral esquerre).
      • Selecciona BIND DNS Server.

      (Si no veus aquesta opció, assegura't que BIND està instal·lat i activat al servidor.)

    4. Crear una nova zona:
      1. Fes clic a l'opció Create a new zone.
      2. Selecciona Master Zone com a tipus de zona.
      3. Introdueix el nom del domini, per exemple, projecte1.aula.
      4. Al camp "File for zone", especifica un nom de fitxer per guardar la configuració (per exemple, db.projecte1.aula).
      5. Clica a Create per guardar la configuració.
    5. Afegir registres DNS:

      6. Després de crear la zona, es mostren opcions per afegir registres DNS (A, CNAME, MX, etc.).

      1. Fes clic a Address per afegir un registre A.
      2. Introdueix el nom del subdomini, per exemple, www, i l'adreça IP corresponent, per exemple, 192.168.1.1.
      3. Repeteix el procés per afegir altres registres com NS, MX, etc.
      4. Fes clic a Save després d'afegir cada registre.
    6. Comprovar i aplicar els canvis:

      7. Fes clic a Apply Configuration per reiniciar BIND i aplicar els canvis.

    7. Comprovar la configuració:

      8. Utilitza eines com nslookup o dig des del terminal per comprovar que el domini resol correctament.

    Agregar dominis usant BIND

    1. Editar el fitxer de configuració de zones, normalment /etc/bind/named.conf.local, i afegir: 
      zone "projecte1.aula" {
    type master;
    file "/etc/bind/db.projecte1.aula";
};
    2. Crear el fitxer de zona amb el següent contingut base: 
      $TTL 86400
@   IN  SOA ns1.projecte1.aula. admin.projecte1.aula. (
        2025010101 ; Serial
        3600       ; Refresh
        1800       ; Retry
        1209600    ; Expire
        86400 )    ; Minimum TTL
@   IN  NS  ns1.projecte1.aula.
ns1 IN  A   192.168.1.1
    3. Reiniciar el servei BIND: sudo systemctl restart bind9.

    Taula de comprovacions

    Comprovació Com fer-ho Esperat
    Comprovar la zona amb Webmin Revisar l'opció de configuració de zones. El domini apareix com a configurat.
    Provar la resolució del domini nslookup projecte1.aula L'adreça IP corresponent es resol correctament.
    Verificar amb BIND sudo named-checkzone projecte1.aula /etc/bind/db.projecte1.aula Cap error en la configuració.

    Com fer una còpia de seguretat

    Per fer una còpia de seguretat de la configuració DNS:

    1. Copiar els fitxers de configuració: 
      sudo cp -r /etc/bind /path/to/backup/bind
    2. Fer una còpia de seguretat de les zones creades: 
      sudo tar -cvzf bind-backup.tar.gz /etc/bind
    3. Guardar la còpia de seguretat en un lloc segur.
